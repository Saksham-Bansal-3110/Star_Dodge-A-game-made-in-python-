# ⭐ Star Dodge (Pygame)

Star Dodge is a simple arcade-style game built using Python and Pygame.  
Your goal is to survive as long as possible by dodging falling stars.

---

## 🎮 Gameplay

- Move the player left and right to avoid falling stars
- Stars spawn faster as time progresses
- The game ends when the player is hit
- Survival time is displayed on the screen
- Background music plays during gameplay

---

## 🕹️ Controls

- **Left Arrow (←)** – Move left  
- **Right Arrow (→)** – Move right  
- **Close Window** – Quit the game

---

## 🧰 Requirements

- Python 3.8 or higher
- Pygame

---

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/star-dodge.git
   cd star-dodge
    ```

2. Install dependencies:

   ```bash
   pip install pygame
   ```

3. Ensure the following files are present in the project directory:

   * `bg.jpg` (background image)
   * `bgm.wav` (background music)
   * `main.py` (game file)

## ▶️ How to Run

```bash
python main.py
```

## 🧠 How It Works

* The player is controlled using keyboard input
* Stars spawn at random horizontal positions
* Falling speed and spawn rate increase over time
* Collision detection ends the game
* Survival time is tracked and displayed
